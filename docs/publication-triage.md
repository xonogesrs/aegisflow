## Method

Every file under the internal trees was classified against four categories and
acted on as follows:

| Class | Action |
|---|---|
| `PUBLIC_DOCUMENTATION` | rewritten from scratch for an external reader (`README.md`, `docs/*.md`, new files) |
| `USEFUL_PUBLIC_ENGINEERING_RECORD` | kept in the publication tree (`docs/governance/*` frozen contracts) |
| `INTERNAL_EVIDENCE` | removed from the publication tree, archived byte-identically |
| `PRIVATE_OPERATIONAL_RECORD` | removed from the publication tree, archived byte-identically |

Nothing was deleted. Every removal has a byte-identical copy in the archive.

## Golden re-derivation

`test/learning/test-incident-observation-profile-1r.mjs` asserts that 13
"opening golden" digests are byte-identical. Those digests depend on the fixture
**identity** inputs, which `makeIdentities()` derived from the operator's scratch
path (`/Volumes/NVM2T/Development/tmp/...`).

That made every golden machine-specific: change the scratch root and all 13
digests change. The fixtures now use a fixed, labeled synthetic root
(`IDENTITY_ROOT = "/autoloop-fixture/scratch"` in
`src/learning/transfer-metrics/fixtures.mjs`), and the 13 goldens were
**recomputed from the same construction the test performs**. The code path is
unchanged; only the identity input is now machine-independent.

This is a deliberate re-baseline, not a weakened assertion: the test still
asserts exact digests, and it now fails if the construction changes.

## What is NOT in `.gitignore` by design

`benchmarks/results/**` is versioned on purpose: the published benchmark's raw
records are part of the evidence, and a benchmark whose raw data is absent is not
reproducible. The directory is small (JSONL, one object per run).
