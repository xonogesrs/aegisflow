# Governed launch evidence

The focused [audit harness](probes/fixed-node-governed-smoke.mjs) created separate temporary OMP config/home, extension copy, session directory, EKM state, CBM cache/runtime, controller root and ledger. It loaded the trusted extension source at this branch HEAD, pinned by SHA-256 and `attestExtension` tree digests. `launchGovernedRuntime` received `env.PATH=/usr/local/bin:/usr/bin:/bin` and a test-only `createControllerGrant`. It launched the installed real OMP binary in RPC mode with seatbelt active; no production Controller secret was used.

The same governed session drove normal prompt, Bash, CBM MCP index/search, EKM query and controller commit. [Raw focused result](evidence/governed-smoke.json) records tool start/end counts, returned data, Node path/version/digest, controller result, ledger witness and identity comparisons. For S09, `probeLedgerForCommit(runtime, bound.identity)` verified MAC-backed ledger state. The harness separately compared controller-result and ledger-record session ID, runtime instance ID and generation to the bound identity; it saw exactly one signed matching commit. This is stronger than terminal text alone.

The R4 [Agent Bash facts](evidence/authority-bash-facts.json), [nested OMP/key denial facts](evidence/authority-nested-key-facts.json) and [forgery facts](evidence/authority-forgery-commit-facts.json) came from existing audit probe cases executed in separate real governed OMP sessions under the same fixed PATH. These cases used temporary controller roots and a local fake provider. The Agent's own Bash performed denial attempts. The harness deliberately injected unsigned/wrong-key records into its isolated ledger to test authenticated rejection.

Deployment restrictions from prior admission remain: C2 requires one local state directory and one live controller per session; C3 requires a new correlator/key per controller instance; C4 treats ledger as durable truth and an unreadable ledger as `UNKNOWN`. This card tested a single isolated controller/session and did not widen those limits.
