8. Architecture and Design Decisions
================================================================================

  - the external verdict IS the receipt: applyExternalReviewVerdict binds CURRENT bundle identity+sha256 + reviewer identity + reviewedAt and thereby proves RECEIVED + REVIEWED

  - repair supersede: new bundle gets a NEW identity (supersedes bound into reviewBundleIdentity), new sha256, explicit SUPERSEDES_* lines, old artifact retained, re-reviewed via a fresh verdict
  - one card -> one complete review bundle -> reviewer receives + reviews the actual content -> verdict (PASS/REPAIR/HOLD) -> card external review complete only on PASS bound to the current bundle
