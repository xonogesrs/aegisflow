8. Architecture and Design Decisions
================================================================================
  - ROOT_CAUSE: Current presentation surface was conflated with unresolved review authority.
  - LATE_DISCOVERY = YES; SAME_LIFECYCLE_FRAGMENTED_ACROSS_CARDS = YES; LOCAL_INVARIANT_OVERRULED_TOP_LEVEL_REQUIREMENT = YES.
  - Process rule: Presentation state must never be used as the sole durable governance authority.
  - Canonical rule: task completion -> review bundle generated -> Current = that task's review; previous verdict / queue state never gates publication.
  - Ledger states: PENDING | REVIEWED | REPAIR | HOLD | ARCHIVED; presentation is the independent isLatestPresented pointer (queue.currentEntryId mirror); state=CURRENT eliminated.
  - Verdict ingest binds the DURABLE LEDGER entry by exact cardId + bundleIdentity + bundleSha256; REVIEW_LEDGER_TARGET_NOT_FOUND / REVIEW_VERDICT_IDENTITY_MISMATCH fail closed; the reviewed card does NOT need to be Current.
  - Verdict lifecycle never controls the presentation pointer: PASS/REPAIR/HOLD update the ledger entry + archive from the immutable ledger artifact; Current files untouched.
  - Stale-replay protection: an older completion (order < presented order) never regresses Current; recovery (--promote/--reconcile) republishes the NEWEST eligible review after a crash.
  - Deterministic migration: QUEUED/CURRENT -> PENDING, RESOLVED -> ARCHIVED, ARCHIVED -> ARCHIVED; identity/sha/verdict/order/supersession preserved; never regenerates bundles; presentation pointer -> newest eligible by completion/publication order.
  - LatestHuman stays the latest completed report of ANY type (operator closeout OR formal review); operator closeouts never touch Current.
  - CBM boundary honored: no broad CBM redesign; PC1 CBM/inheritance implementation untouched.
