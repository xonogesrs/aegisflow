8. Architecture and Design Decisions
================================================================================
  - MemoryRecordV1 = autoloop.memory-record/v1; fixed envelope schema/recordId/recordType/identity/subject/content/source/scope/trust/validity/lifecycle/timestamps/evidence/security/metadata; unknown schema/type fails closed
  - recordId = sha256(recursiveCanonical({schema, recordType, identity, subject, scope, sourceIdentity})); logicalKey = sha256(canonical({schema, recordType, identity, scope})); contentHash = sha256('content:'+canonical(content)); metadata/lifecycle/evidence/timestamps never change recordId
  - strict canonical JSON: code-point key sort, array order preserved, undefined/NaN/Infinity/BigInt rejected, Date->RFC3339 UTC, raw strings; CBM-1 shallow-replacer collision codified as zero-tolerance
  - trust ladder RAW->UNVERIFIED->VERIFIED->REVIEWED->CONFIRMED; writer/repair self-promotion always rejected; VERIFIED needs verifier evidence identity; REVIEWED needs independent review + empty blocking; CONFIRMED needs Controller ruling; skip-level needs explicit import contract; downgrades create DOWNGRADED lifecycle events
  - validity CURRENT/STALE/INVALIDATED/TOMBSTONED/CONFLICTED; tree/commit/worktree/content baseline changes mark STALE; STALE never a trusted final answer; tombstone keeps identity+history; conflicts surfaced together (never silently merged)
  - scope model: repository/worktree/commit/tree/path/symbol/content/graphRun/task/global; worktree = hard isolation boundary; tree-bound CODE carries validityTree; execution memory always graphRun-bound; decision memory may be global-scoped with authority
  - lifecycle events append-only: CREATED/VALIDATED/PROMOTED/DOWNGRADED/MARKED_STALE/INVALIDATED/TOMBSTONED/SUPERSEDED/RESTORED/MIGRATED; history never overwritten
  - evidence: manifestDigest + items(allowlisted regular files, no symlink, no escape, hash recomputed) + verifier/review/controller identities gated by trust
  - SQLite primary (node:sqlite, zero deps): foreign_keys ON, WAL, synchronous NORMAL; tables memory_records/lifecycle_events/evidence/relationships/conflicts/migrations; FTS5 ADOPTED with PINNED tokenizer 'unicode61 remove_diacritics 0' (SQLite 3.53.2); normal (non-contentless) FTS table for deterministic rebuild
  - JSONL journal: autoloop.memory-journal-event/v1; hash chain eventDigest = sha256(canonical({journalSequence,eventId,recordId,operation,payloadDigest,previousDigest})); fixed genesis; fsync per append; partial trailing line detected; corrupted middle line fail-closed; SQLite rebuild from journal verified identity-equal
  - migration v1 with checksum; unknown FUTURE version fails closed (MIGRATION_INVALID)
  - security: reuse scanForSecrets on RAW string fields (JSON escaping weakens quote-sensitive patterns); ingestion allowlist/denylist; hostile text stored as DATA only; no SQL injection (parameterized queries); secret rejected before journal append
