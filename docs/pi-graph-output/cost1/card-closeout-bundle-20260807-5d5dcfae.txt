8. Architecture and Design Decisions
================================================================================
  - contract autoloop.telemetry-event/v1: allowlist schema（unknown fields/versions fail closed）; deterministic eventId = sha256(canonical({graphRunId, eventType, nodeId, attempt, sequence})); event types graph.run / node.run / node.repair / graph.closeout / retrieval.observed / verification.recorded / telemetry.availability / telemetry.overhead
  - token policy: tokenSource is NOT_REPORTED and token counters MUST be null unless a provider surface reports usage（PROVIDER_REPORTED）. Audit finding: the execution layer exposes no LLM usage metadata（executor = colima-container, reviewer = deterministic-c3; sub-agent results carry no tokens/model/tool counters）→ aggregates surface reportedTokens / tokenCoverage / unknownUsageCount instead of fabricated totals
  - security boundary（allowlist）: telemetry stores identities + counters + timings + digests ONLY; secrets/credentials/prompts/responses/memory bodies/source blobs/stdout/stderr/db contents/user data denied at schema + content-scan layers（reuse review-bundle secret-scan principle）; memory-content leakage prevented by recording retrieval COUNTERS + digests, never selectedRecords
  - storage: local JSONL（autoloop.telemetry-store/v1）with header + per-line validation; open re-validates the full stream（corrupt line / tampered event → TELEMETRY_STORE_INVALID fail-closed）; bounded growth via rotation（active cap maxEvents/maxBytes → archived chunks, no silent loss）; explicit lifecycle open/append/readAll/close; no cloud / no external service
  - passive instrumentation: runColimaGraph gains an OPT-IN telemetry param; the observer runs AFTER the graph result + closeout gate are final（try/catch; failures degrade to TELEMETRY_UNAVAILABLE and never alter task semantics / scheduler ordering / writer lease / review verdict / repair budget / retrieval ranking / model / context selection）; a corrupt telemetry store surfaces TELEMETRY_STORE_INVALID（caller decides fail-closed policy for canonical metrics; the graph itself already completed）
  - aggregate autoloop.telemetry-aggregate/v1: totalDurationMs, reportedTokens（input/output/cachedInput/total）, tokenCoverage, unknownUsageCount, toolCallCount, retrieval counters/bytes/digests, subAgentCount, repairCount, reviewerCount, verification sums, finalVerdict/holdCode, aggregateIdentity（deterministic）
  - budget contract autoloop.telemetry-budget/v1: tokenBudget / timeBudget / toolCallBudget / retrievalByteBudget / researchQueryBudget / retryBudget / repairBudget / subAgentBudget with {limit, unit, policy, enforced:false} — validation + simulateBudgetEnforcement only; enforced MUST be false in COST-1（no production routing change）
  - metric source map（src/telemetry/source-map.mjs）: machine-readable; every metric tagged source / authoritative / availability / lifecycleBoundary / deterministic / nullable / providerExposed. Summary: 34 metrics = 24 available / 2 partial / 8 NOT_REPORTED
  - overhead gate（stage 8）: telemetry disabled = 0 overhead by construction（no hot-path observer）; enabled observation measured by scripts/cost1-telemetry-probe.mjs（sub-ms per event, bounded bytes/event, rotation accounting）; graph-level delta covered by the closeout graph + colima-all evidence
  - OpenTelemetry readiness: naming/semantic mapping + exporter seam are research output only（source map + contract are OTel-compatible event/span abstractions）; no collector / backend deployed
  - budget enforcement, model routing, review-depth reduction, self-evolution tuning, and CBM-4 write-back are EXPLICITLY deferred（later Cost Optimization / CBM-4 stages）
