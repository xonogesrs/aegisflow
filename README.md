# autoloop

Standalone bootstrap of the provider-neutral AutoLoop core (task-card
lifecycle primitives, C2D atomic state machine, normalization, schema
validation).

Status:

- Standalone bootstrap only. Not production ready.
- No provider adapter is wired in (no OpenCode, no Pi, no Claude Code, no
  Codex).
- No task cards are executed by anything in this repository yet.

Extracted from Aura (`scripts/ai/autoloop/`) under
`AUTOLOOP_STANDALONE_COPY_AND_BOOTSTRAP`. The Aura source tree is
unmodified by this extraction.
